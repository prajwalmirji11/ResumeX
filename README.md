# ResumeX \- AI Powered Resume Screening System

## Overview

Recruiters often spend hours manually reviewing resumes to find the right candidates. ResumeX simplifies this process by automatically analyzing resumes and matching them against job requirements.

This project uses Natural Language Processing (NLP) and Machine Learning techniques to extract important information from resumes, evaluate candidate profiles, and provide meaningful insights that help streamline the hiring process.

Whether you're a recruiter trying to shortlist candidates quickly or a student exploring AI applications in HR technology, ResumeX demonstrates how intelligent automation can improve recruitment efficiency.

## Features

- Upload and analyze resumes in PDF format
- Extract key candidate information automatically
- Identify and categorize technical skills
- Compare resumes against job descriptions
- Generate candidate matching scores
- Simple and user\-friendly interface
- Fast and automated screening process
- Data\-driven candidate evaluation

## How It Works

1. The user uploads a resume.
2. The system extracts textual information from the document.
3. NLP techniques process and clean the extracted text.
4. Skills, qualifications, and relevant keywords are identified.
5. The resume is compared with job requirements.
6. A matching score and analysis are generated to assist in candidate selection.

## Technology Stack

- Python
- Streamlit
- Natural Language Processing (NLP)
- Machine Learning
- Pandas
- Scikit\-learn
- PDF Processing Libraries

## Project Motivation

Hiring teams often receive hundreds of applications for a single role. Reviewing each resume manually is time\-consuming and prone to human bias. ResumeX was developed to automate the initial screening process, helping recruiters focus on the most relevant candidates while reducing effort and improving consistency.
